## 📖 About This Repository

This repository is my **personal DSA learning journal** written in C++.

Every folder represents a topic I studied — from basics like arrays and recursion, all the way to advanced structures like tries, heaps, and graphs. The problems here are a mix of self-practice, college assignments, and LeetCode solutions, all implemented from scratch to build a strong foundation.

> _"The best way to learn DSA is to code it yourself."_

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/vishalsr20/DSA-C-Plus-Plus.git
cd DSA-C-Plus-Plus/C++

# Compile and run any file
g++ -std=c++17 -o out <filename>.cpp && ./out
```

**Prerequisites:** GCC 7+ or Clang 5+. No external dependencies — every file is standalone.
